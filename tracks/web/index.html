Сделать сейчас

Одна страница → один файл → рабочая ссылка

GitHub не является обязательным входом. Сначала сайт должен работать локально. Публикация — отдельный последний шаг.

Стартовый запрос
Я хочу сделать маленький сайт, который можно открыть обычным двойным кликом по index.html и потом бесплатно опубликовать без GitHub.

Сначала задай мне 3 вопроса: для кого сайт, что человек должен понять или сделать, и какой один результат я хочу получить сегодня.
После ответов предложи структуру максимум из 5 блоков. Когда я подтвержу — дай полный код одного index.html: HTML + CSS + JavaScript внутри файла, без библиотек и сборки. Код должен работать локально.
В конце дай инструкцию: как сохранить файл, открыть его и что проверить.
После первого ответа не начинай новый чат — улучшай этот.
Публикация

Бесплатный хостинг без Git

Не привязываемся к одному сервису. Выбираем по принципу: бесплатно → открывается в браузере → можно загрузить обычные файлы → есть понятный адрес сайта → ученик сохраняет исходники у себя.

Что использовать на занятии прямо сейчас

Быстрый путь: Netlify Drop. Российские кандидаты на основной школьный хостинг: Free Sprinthost и Beget FreeHosting. Их публичные страницы, условия и файловые сценарии проверены 29.09.2026; фактическую регистрацию и загрузку со школьного ПК надо один раз пройти руками, потому что они требуют создания аккаунта, а Beget ещё и собственного мобильного номера.

Free Sprinthost · сильный российский кандидат

Постоянно бесплатный хостинг без рекламы: 1 ГБ, браузерная панель с файловым менеджером и бесплатный технический адрес вида f000000.xsph.ru.

РФ · 1 ГБ · file manager

Условие: входить в панель не реже одного раза в 30 дней; полноценной техподдержки бесплатного тарифа нет.

Открыть сервис ↗

Beget FreeHosting · полноценный хостинг

1 ГБ, один сайт, файловый менеджер, FTP, MySQL, PHP/Python, без рекламных баннеров. Подходит не только для статической страницы.

РФ · 1 ГБ · PHP/MySQL

Для регистрации нужны ФИО, email и собственный действующий мобильный номер. Поэтому для младших логичнее школьный/преподавательский аккаунт, а не обязательная личная регистрация.

Открыть сервис ↗

Netlify Drop · самый простой быстрый publish

Перетащи папку или ZIP — получишь URL. Git-репозиторий не нужен. Хорош для первого статического проекта.

Cloudflare Pages Direct Upload · резерв

Загрузка готовых файлов напрямую. Статические запросы на Free бесплатны; dashboard drag-and-drop ограничен 1000 файлами.

pages.dev

Direct Upload-проект потом нельзя переключить на Git integration; dashboard drag-and-drop не компилирует functions/.

Открыть Cloudflare ↗

Tiiny Host · очень простой ZIP-hosting

На Free: один активный сайт, ZIP/HTML до 3 МБ, до 5000 посещений и 5 ГБ трафика в месяц. Подходит для маленького школьного демо.

1 сайт · 3 МБ

До 3 загрузок/обновлений в сутки; чтобы бесплатная ссылка оставалась активной, надо входить в аккаунт хотя бы раз в 3 месяца. На Free показывается небольшой banner сервиса.

Открыть сервис ↗

Neocities · учебный статический веб

Бесплатный static hosting, HTML-редактор прямо в браузере и drag-and-drop файлов. Хорош для обучения HTML/CSS и личных творческих страниц.

browser editor · drag & drop

Это ещё и публичное веб-сообщество/галерея сайтов. Для школьников не использовать как место для личных данных.

Открыть сервис ↗

InfinityFree · бесплатный «взрослый» хостинг

5 ГБ, бесплатные поддомены, online File Manager, PHP 8.3, MySQL/MariaDB, SSL и без рекламы на сайте.

5 ГБ · PHP/MySQL

Сильнее, чем нужно для первого index.html; использовать, когда проекту уже нужны серверные возможности.

Открыть панель ↗

AwardSpace · ещё один полный FreeHosting

Бесплатный тариф без рекламы: 1 ГБ, бесплатный поддомен, web File Manager, PHP/MySQL; можно разместить до четырёх сайтов/поддоменов в рамках бесплатного аккаунта.

1 ГБ · File Manager

Иностранная панель и больше настроек, поэтому это резерв, а не самый простой старт для младших.

Открыть сервис ↗

Timeweb · не считать постоянным Free

Хорошая российская панель и файловый менеджер, но бесплатный режим — только 10-дневный тестовый период (поддержка может продлить ещё на 10 дней).

Полезен для истории версий и нормальной разработки, но не должен блокировать первый результат на школьном компьютере.

Что проверить

Сайт готов не когда «код написан»

На компьютере

Открывается, кнопки работают, текст читается.

На телефоне

Нет горизонтального скролла, кнопки нажимаются.

Без ИИ

Ученик может объяснить, что делает сайт и что изменил сам.

После публикации

Открыть ссылку в инкогнито и убедиться, что она доступна не только на исходном ПК.

Не обязан заканчивать всё сегодня.

Сохрани рабочий файл, ссылку или исходники. На следующем занятии продолжай с последней работающей версии, а не начинай заново.

Статус: школьный браузерный сценарий, обновлено 29.09.2026. Внешние сервисы меняются — перед важным использованием проверяем доступ заново.
