Стартовый запрос
Я хочу сделать маленький сайт, который можно открыть обычным двойным кликом по index.html и потом бесплатно опубликовать без GitHub.

Сначала задай мне 3 вопроса: для кого сайт, что человек должен понять или сделать, и какой один результат я хочу получить сегодня.
После ответов предложи структуру максимум из 5 блоков. Когда я подтвержу — дай полный код одного index.html: HTML + CSS + JavaScript внутри файла, без библиотек и сборки. Код должен работать локально.
В конце дай инструкцию: как сохранить файл, открыть его и что проверить.
После первого ответа не начинай новый чат — улучшай этот.
Публикация

Бесплатный хостинг без Git — по умолчанию

Для школы нужна публикация из папки, а не настройка репозитория.

Netlify Drop · основной простой путь

Перетащи папку или ZIP — получишь URL. Git-репозиторий не нужен.

drag & drop

Cloudflare Pages Direct Upload · резерв

Тоже принимает готовые файлы напрямую. Статические запросы на Free бесплатны; drag-and-drop ограничен 1000 файлами.

pages.dev

GitHub Pages · позже

Полезен для версий и командной разработки, но не блокирует первый результат на школьном ПК.

не prerequisite
СохраниСоздай папку проекта и файл index.html.
Проверь локальноДвойной клик → сайт должен работать без сервера.
УнесиСкопируй всю папку на флешку/в облако/на телефон.
ОпубликуйNetlify Drop; если недоступен — Cloudflare Direct Upload.
Официально: Netlify Drop не требует Git. Cloudflare Pages Direct Upload поддерживает drag-and-drop. Лимиты Free: официальная таблица.

Важно для Cloudflare: проект, созданный через Direct Upload, нельзя позже переключить на Git integration — для Git создаётся новый проект. Dashboard drag-and-drop также не компилирует папку functions/; для Pages Functions нужен Wrangler или Git-based deployment. Для нашей первой статической страницы это ограничение не мешает.
Что проверить

Сайт готов не когда «код написан»

На компьютере

Открывается, кнопки работают, текст читается.

На телефоне

Нет горизонтального скролла, кнопки нажимаются.

Без ИИ

Ученик может объяснить, что делает сайт и что изменил сам.

После публикации

Открыть ссылку в инкогнито и убедиться, что она доступна не только на исходном ПК.

Не обязан заканчивать всё сегодня.

Сохрани рабочий файл, ссылку или исходники. На следующем занятии продолжай с последней работающей версии, а не начинай заново.

Статус: школьный браузерный сценарий, обновлено 29.09.2026. Внешние сервисы меняются — перед важным использованием проверяем доступ заново.
