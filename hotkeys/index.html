Горячие клавиши

Шесть сочетаний, которые экономят время почти на каждом занятии. Их достаточно, чтобы быстро копировать запросы, переключаться между окнами и работать с многострочным текстом.

Ctrl+A

Выделить всё

Выделяет весь текст в текущем поле или документе. Полезно перед копированием полного запроса, ответа или диалога.

Ctrl+C

Копировать

Копирует выделенный текст или объект в буфер обмена. После этого его можно вставить в другой сервис или форму.

Ctrl+V

Вставить

Вставляет содержимое буфера обмена. Используй для переноса запросов, ссылок и результатов между вкладками.

Shift+Enter

Новая строка без отправки

В большинстве AI-чатов переносит курсор на новую строку, не отправляя сообщение. Удобно для длинных структурированных запросов.

Alt+Tab

Переключиться между окнами

Переходит между открытыми программами и окнами Windows: например, Edge → Проводник → обратно в Edge.

Ctrl+Tab

Следующая вкладка браузера

Переключает вкладки внутри текущего окна браузера. В «КУРС ИИ» удобно переходить: сайт → DeepSeek → GitHub → MAX.

Не путай: Alt+Tab — между окнами Windows. Ctrl+Tab — между вкладками внутри браузера.
