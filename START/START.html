Одно фото.
Два подхода. Два шага.

Сначала меняем среду. Затем вторым промптом дорабатываем уже полученное изображение и проверяем, насколько точно модель выполняет локальную правку.

LIVE: два окна ChatGPT → Win+Z → 50/50 → одно фото в оба → слабый слева → сильный справа.

ВАУ · теперь результат

Два подхода. Две стадии результата.

Первая картинка — после промпта 1. Вторая — после доработки промптом 2. Так видно не только генерацию, но и точность последующего редактирования.
