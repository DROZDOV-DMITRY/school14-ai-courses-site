УЧЁБА · От вопроса — к реальной задаче

Ответ может звучать правильно — и всё равно не решать твою задачу.

Обычный чат с ИИ
Объясни мне квадратные уравнения.
Квадратное уравнение имеет вид ax² + bx + c = 0. Для решения можно использовать дискриминант D = b² − 4ac…
Где именно ошибка?
Какой уровень?
Сколько времени?
Какой результат нужен?
Реальная задача
Я в 8 классе. Завтра самостоятельная по квадратным уравнениям. Формулу знаю, но путаюсь при переносе и проверке. У меня 25 минут. Сначала задай 2 коротких вопроса, затем разберём 1 пример вместе и дай 2 для тренировки. Не решай за меня.
ЦЕЛЬКОНТЕКСТОГРАНИЧЕНИЯФОРМАТКРИТЕРИЙ
Начнём с диагностики. 1) Где чаще ошибка: перенос или подстановка? 2) Покажи один пример, где ответ не сошёлся — найдём точку ошибки.
